# 热点图文批量生产工作台

热点图文批量生产工作台是一款面向本地内容生产的桌面工作台，帮助用户从实时热点或自定义话题出发，完成资料整理、文章生成、配图配置、人工审核和本地导出。

## 项目最初目标

- 将热点发现、资料整理和图文创作集中到一个清晰的本地工作流中。
- 支持使用公开资料辅助生成内容，并区分已知事实、待核实信息和分析判断。
- 保留人工编辑、审核和发布前核对环节，避免把未经确认的内容直接当作事实交付。
- 支持从单个话题扩展到多话题、多角度的批量创作。
- 通过本地数据保存和可追溯的版本、任务及导出结果，方便后续复查和继续编辑。

## 适用人群

- 需要持续整理热点、制作图文内容的个人创作者和内容运营人员。
- 负责公众号、短视频图文、资讯栏目或品牌内容的编辑团队。
- 需要先完成资料核对，再批量生成不同角度文章的研究、策划和营销人员。
- 希望在本地保存文章、模型配置和导出文件，并保留人工审核控制的用户。

## 当前主要能力

- 浏览热点来源，或输入自定义话题和参考链接。
- 选择单热点多角度或多热点创作模式。
- 配置文本和图片模型，支持官方服务商、OpenAI 兼容接口、API 中转和自定义 Base URL。
- 生成文章、封面和正文配图，并对生成结果进行独立验收后再应用。
- 对文章版本、图片组合和审核状态进行持久化管理。
- 导出 Word 和 ZIP 文件，并保留发布前人工核对提示。
- 本地保存任务、文章版本、生成结果和审核事件；敏感凭据不写入文章、任务或导出文件。
- Windows 桌面启动、标准安装器、卸载和用户数据保留流程。

## Product V0.1 最新改动

当前开发主线为 `product/v0.1`。近期改动已完成 Product V0.1 主链的核心基础设施：

- 建立 Product V0.1 的项目、话题、批次、文章、文章版本、图片素材、生成任务和导出任务模型。
- 增加数据库迁移、旧数据保留和版本快照机制。
- 增加文章审核、图片审核和最终审核状态机，以及内容或图片变化后的审核失效规则。
- 增加文本和图片生成执行适配器，将模型调用、结果保存、结果验收和结果应用分开处理。
- 增加可追溯的生成结果工件，限制可写入文章和图片素材的字段范围。
- 增加 Product readiness 校验，并将 Word/ZIP 导出接入当前 Product 文章版本和图片组合。
- 修复本地 UI 到 API 的系统代理干扰：UI 访问本机 API 时使用 `trust_env=False`，外部 Provider 的代理语义保持不变。

当前状态：软件可以打开正常工作台，License Gate 不阻塞开发环境；项目仍处于真实用户手工验收阶段，模型服务商的实际配置和接口能力需要由用户在模型设置中确认。模型列表自动发现不是使用模型的必要条件，无法自动发现时可以手动填写模型名称，并单独进行基础连接和实际生成测试。

## 技术栈

- Python 3
- Streamlit：本地工作台界面
- FastAPI + Uvicorn：本地 API 服务
- SQLite：本地项目、任务、版本和审核数据
- HTTPX：模型服务、热点来源和网络请求
- Pillow：图片校验和处理
- python-docx：Word 导出
- cryptography：本地凭据和许可证相关安全能力
- Windows 启动与安装：PowerShell、C# Bootstrapper、Inno Setup

## 本地启动

使用桌面启动器：

```text
/Users/mac/Desktop/热点图文批量生产工作台.command
```

或在项目目录中使用项目虚拟环境启动对应的 API 和 Streamlit 服务。默认本地界面地址为：

```text
http://127.0.0.1:8505
```

## 开发与测试

项目测试配置位于 `pytest.ini`，项目虚拟环境中的 pytest 可用于运行定向测试、Product V0.1 回归和集成测试：

```bash
.venv/bin/python -m pytest -m "product_v01 or db_safety"
.venv/bin/python -m pytest -m integration
```

真实模型调用可能产生费用，并受服务商的密钥、权限、额度、接口路径和限流策略影响。正式内容发布前请始终人工核对来源、事实、版权和平台规则。
