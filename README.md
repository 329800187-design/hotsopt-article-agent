# 热点图文批量生产工作台

## 项目简介
热点图文批量生产工作台是一个面向 Windows 的热点内容生产桌面工具，目标是帮助普通用户围绕真实热点资料，批量生成文章、配图和可导出的 Word 成稿。

当前项目采用本地桌面壳 + 本地 API + 可配置文本/图片模型的架构，重点覆盖以下能力：
- 热点抓取与自定义话题输入
- 单热点多角度文章生成
- 图片预算控制，支持纯文字、经济型、标准型三种方案
- 非 JSON 模型响应自动降级为可编辑文章
- 模型异常时使用公开资料生成本地基础稿
- Word 导出与来源格式规范化
- Inno Setup 安装、卸载与用户数据保留
- 离线许可证激活
