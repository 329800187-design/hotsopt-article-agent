# 热点图文批量生产工作台 RC1.3.3-Lite-R2.2.21

当前版本：RC1.3.3-Lite-R2.2.21

权威状态以 [STATUS.md](./STATUS.md) 为准。

本轮以 1000 元客户版最终可交付收口为目标，定位为：真实热点资料辅助整理＋AI 文章和图片批量生成工具。

核心能力：

- 使用 Inno Setup 生成标准 Windows 安装器。
- 默认程序目录：`%LOCALAPPDATA%\Programs\热点图文批量生产工作台`。
- Windows 唯一用户数据目录：`%LOCALAPPDATA%\热点图文批量生产工作台`，源码、Launcher 和安装版一致。
- 开发和验收优先使用 `start-dev.ps1`。即使直接运行 Python 或 Streamlit，Windows 默认数据目录也与安装版一致。
- 支持单热点生成 1～5 篇不同角度文章。
- 支持 1～5 个热点各生成 1 篇文章。
- 总文章数最多 5 篇，最大并发固定 2。
- 自动资料搜索限时，不再无限卡在“正在查找资料”。
- 质量门禁只阻断无依据硬事实；普通分析、趋势判断、影响推测和观点总结不阻断导出。
- 图片方案保留纯文字、经济模式、标准模式；标准模式每篇 1 张封面＋1 张正文图。
- 图片真实测试入口常显，确认后只调用 1 次图片模型，自动重试 0 次。
- 客户可见 Word/ZIP 只包含标题、导语、正文与图片，不输出资料来源、原文链接、AI 声明或内部质量信息。

完成状态：`RC1.3.3-Lite-R2.2.21 许可证、三图导出和安装配置保留修复进行中；待 Mac 与 Windows 全量复验`
