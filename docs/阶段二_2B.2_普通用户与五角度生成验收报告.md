# 阶段二 2B.2 普通用户与五角度生成验收报告

## 1. 验收范围

本阶段在 2B.1 基础上增量实现普通用户创作流程和 `single_topic_multi_angle` 批次。本阶段未开发 2B.3，也未加入多张正文图、编辑器、Word 排版、自动发布或定时调度。

## 2. 实现摘要

- 普通导航收敛为：首页、选择话题、开始生成、我的内容、模型设置；技术页面位于高级设置。
- 新增五种固定角度：新闻资讯、社会观察、情绪共鸣、观点评论、故事化解读。
- 单热点模式严格创建 1～5 个不同角度的独立子任务，复用现有单篇状态机、文章模型和封面模型。
- 角度计划、角度快照、相似度状态/分数和重写次数写入现有批次、批次项目和任务记录。
- 相似度不通过时只重写违规子任务，沿用原 task_id，最多自动重写 2 次；仍不通过时标记为需要检查。
