# 热点图文工作台 L1 离线授权客户使用说明

## 第一次使用

1. 双击客户包中的 `start.vbs`。
2. 打开软件后进入激活页面。
3. 将页面显示的设备码发给软件提供方。
4. 收到 `.license` 文件后，在激活页面选择文件并导入。
5. 显示“授权有效”后，即可使用许可证包含的生成能力。

## 设备码与许可证

设备码只用于绑定当前电脑。许可证在本机校验，不需要联网激活，也不会上传 API Key、签名或设备原始标识。

## 未激活时

已有文章、图片和导出结果仍可查看；需要许可证的文章、图片和批量生成操作会提示先激活。

## 更换电脑

新电脑需要重新提供新设备码申请许可证。不要手动编辑许可证文件，修改后签名会失效。

## 安全提醒

请不要公开分享许可证文件、API Key 或客户数据目录。软件包内不包含许可证签发私钥。
