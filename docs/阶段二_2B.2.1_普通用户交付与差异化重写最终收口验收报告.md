# 阶段二 2B.2.1 普通用户交付与差异化重写最终收口验收报告

## 1. 范围

本轮只收口普通用户交付、差异化重写、相似度审计和结果版本保护，不进入 2B.3，不开发正文多图、Word、ZIP 导出、自动发布或授权码。

## 2. 差异化重写

- `BatchExecutor._prepare_rewrite()` 保存冲突文章标题、前 200 字、小标题结构、冲突相似度项、当前角度和开头策略。
- `single_task.py` 从任务选项读取 `rewrite_context`，传入 `_prompt()` 和 `generate_article()`。
- 重写提示词明确要求不复用旧标题结构、不使用相同开头、调整段落顺序、更换核心论述并避开高频表达。
- 首次提示词与重写提示词不同；自动重写上限仍为 2 次。

## 3. 相似度证据

三篇既有真实任务重新计算，不重新消耗模型费用。证据文件：`evidence/phase2b2-live/multi_angle_live_smoke.json`。

- `total_pairs_checked=3`。
- 保存 3 组两两比较，每组包含标题、开头、结构、正文、整体相似度和 `status`。
- `violating_pairs` 单独保存；没有违规时仍保留 3 组比较，不能误写为 `pair_count=0`。
- 每篇任务保存：`angle_id`、`similarity_status`、`rewrite_count`、`article_sha_before`、`article_sha_after`、`prompt_sha_before`、`prompt_sha_after`、`cover_prompt_sha`。
- 现有真实批次最终状态：`completed`；三篇 `similarity_status=passed`；其中观点评论任务保留 `rewrite_count=2`。

## 4. 普通模型设置页

普通“模型设置”页直接提供服务商、API Key、文本模型、图片模型和“保存并检测”。已提供预设：阿里云百炼、火山引擎、智谱 GLM、DeepSeek、OpenAI 兼容、自定义。Base URL、Endpoint、鉴权和 Header 仍只在高级设置中使用。

普通页只显示中文结果：文本模型连接成功、图片模型连接成功、API Key 无效、当前接口不能生成图片、网络连接异常；不显示原始 JSON、HTTP 状态、Provider 响应或 traceback。

## 5. 我的内容

- 每篇内容提供取消这篇、重新生成这篇、查看文章和查看封面。
- 系统根据失败阶段自动选择文章或封面重试。
- `review_required` 显示“这篇内容与其他文章较接近，建议重新生成。”并提供重新生成按钮。
- 普通用户术语使用“本次创作”“我的创作”“开始生成”“停止本次创作”。

## 6. 结果版本保护

- 重写文章和封面先写入 `data/tasks/<task_id>/.attempts/attempt-*` 临时目录。
- 新文章和新封面全部成功后，使用 `Path.replace` 原子替换正式文件。
- 重写失败保留上一版本，并显示“新版本生成失败，当前展示上一版本”。
- 普通页面只在当前封面状态为 `completed` 时展示封面，避免旧封面冒充新结果。
