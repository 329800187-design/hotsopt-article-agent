# RC1.3 UI 设计说明

## 设计目标

RC1.3 保持 Streamlit 业务界面不变，新增客户交付壳，优先解决“不会技术也能启动和激活”的问题。

## 客户入口

- 客户只需双击 `Hotspot Article Agent.exe`。
- 启动器隐藏 PowerShell、API 和 Streamlit 控制台，并自动打开浏览器。
- 默认端口被占用时自动选择可用端口，不要求用户填写 localhost 地址。
- 重复双击复用现有服务，不创建重复进程。

## 首次使用

- 未激活时直接显示中文激活向导。
- 页面显示设备申请码，支持复制给软件提供方。
- 客户可粘贴完整许可证内容，也可选择许可证文件；设备申请码本身不是许可证。
- 激活成功后进入模型设置页，API Key 只保存在本机用户数据目录。

## 数据隔离

客户包内只读业务程序、内置 Python 3.12 Runtime 和资源；数据库、设置、日志、缓存、任务与导出统一写入 `%LOCALAPPDATA%\\热点图文工作台`。

## 视觉原则

沿用现有品牌 Logo、米白内容区和深色导航，不使用紫蓝霓虹、机器人或魔法棒式 AI 模板。普通用户页面隐藏 task_id、HTTP 状态、原始 JSON、traceback 和英文错误码。
