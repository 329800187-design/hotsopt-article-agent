# L1 离线许可证签发说明

本说明只供开发者或交付人员使用。L1 使用 Ed25519 离线签名，不包含服务器、在线激活、心跳、支付或远程授权接口。

## 签发前

1. 在客户电脑运行软件并复制设备码。
2. 确认客户名称、许可证有效期和功能范围。
3. 确认签发私钥位于项目目录之外的受保护目录。

## 签发方式

使用 `license_admin/license_generator.py` 或图形工具生成许可证。签发工具从 `HOTSPOT_LICENSE_PRIVATE_KEY` 或开发者专用目录读取私钥，项目目录和客户包都不保存私钥。

## 交付前检查

- 许可证的产品为 `hotspot-article-agent`。
- 设备码与客户设备完全一致。
- `not_before` 不晚于交付时间，`expires_at` 晚于 `not_before`。
- 功能列表与合同范围一致。
- 只把生成的 `.license` 文件交给对应客户。

## 禁止事项

不得把私钥、完整 API Key、Authorization Header 或签发工作目录放进 Source、Windows 或 Upload 包。
