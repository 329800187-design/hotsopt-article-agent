# 阶段二 2B.1：批次任务与独立子任务验收报告

## 1. 范围

本阶段只实现 `multi_topic` 批次：1～5 个不同话题，每个话题创建一个独立单篇子任务。未开发五角度、多正文图、编辑器、Word 排版、自动发布或定时调度。

## 2. 实现内容

- 新增 SQLite 表：`generation_batches`、`generation_batch_items`。
- 批次和子任务在同一事务中创建，保存完整脱敏话题快照和独立 `generation_options`。
- 新增 `generation/batch_executor.py`，复用现有单篇执行器；默认并发 2，允许 1～3。
- 支持批次开始、单篇取消、批次取消、单篇重试和重试全部失败项。
- 子任务失败不影响其他 Future；批次统计从 SQLite 子任务状态重新计算。
- 启动恢复先执行单篇恢复，再汇总和恢复批次；已完成批次不降级。
- Streamlit 增加“批量生成”和“批次任务”入口，页面状态来自 API/SQLite。

## 3. API

- `POST /api/batches`
- `GET /api/batches`
- `GET /api/batches/{batch_id}`
- `GET /api/batches/{batch_id}/items`
- `POST /api/batches/{batch_id}/start`
- `POST /api/batches/{batch_id}/cancel`
- `POST /api/batches/{batch_id}/retry-failed`
- `POST /api/batches/{batch_id}/items/{task_id}/cancel`
- `POST /api/batches/{batch_id}/items/{task_id}/retry`

所有接口使用统一 `success/data/error/request_id/timestamp` 响应，并经过共享递归脱敏。
